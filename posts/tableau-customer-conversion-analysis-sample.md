## 第一阶段：需求分析与规划

1. 明确核心业务目标

* **核心问题**: 我们需要深入分析“红旗酒”系列产品的老客户（已购买前几代产品的用户）在新一代产品（第四代）中的转化情况。这不仅仅是看一个总体的复购率，而是要分代际、分渠道地进行精细化洞察。

* **业务价值与运营作用**:

  * **评估客户忠诚度与产品粘性**: 转化率的高低直接反映了老客户对“红旗酒”品牌的认可度和忠诚度。高转化率意味着产品成功地建立了用户心智，运营策略上可以考虑推出更多针对高价值老客户的回馈活动。

  * **衡量新品发布效果**: 通过对比不同代际客户的转化率，可以判断新品的吸引力是增强了还是减弱了，为未来产品迭代和市场定位提供关键依据。

  * **精准营销的数据支持**: 识别出已转化和未转化的客户群体，是实现精准营销的基础。运营团队可以针对“已转化”的高价值客户进行追加销售或增值服务推荐；同时，针对“未转化”的老客户，可以进行定向的激活、召回活动，如发送专属优惠券、进行电话回访等，从而提升整体销售额。

- 定义关键问题与分析指标

* **关键业务问题**:

  1. *“购买过第一代的老客户，有多少比例购买了第四代？”* (同样的问题适用于第二代和第三代客户)

  2. *“哪个分公司的客户转化工作做得最好？是否存在可以被复制的最佳实践？”*

  3. *“具体是哪些客户转化了？他们由哪些销售人员跟进？他们的历史购买行为是怎样的？”*

  4. *“那些没有转化的老客户，他们是谁？把名单找出来以便跟进。”*

* **核心指标 (KPIs) 的设计与运营作用**:

  * **各代际客户转化率 (`1代/2代/3代客户转化率`)**:

    * **作用**: 这是回答第一个关键问题的核心指标。通过对比这几个转化率，管理者可以判断出哪一代产品的客户基础最为稳固。例如，如果1代客户转化率依然很高，说明产品的长期价值深入人心。

  * **已转化/未转化客户数**:

    * **作用**: 每个分公司的转化率点击之后联动显示，这两种类型的客户数，可以看到规模。

  * **整体历史客户转化率 (`历代(1 2 3)客户转化率`)**:

    * **作用**: 提供一个宏观的视角，了解整个“红旗酒”老客户群体的基本盘。

- 识别用户与受众

* **主要用户**: 销售管理层、市场部分析师。

* **使用场景与价值**:

  * **销售管理层**: 他们需要快速概览整体和各分公司的转化表现，用于**复盘会议**和**绩效评估**。仪表板顶部的KPI区和按分公司排序的主视图正是为此设计的，让他们能在30秒内掌握核心情况。

- 设计原型与线框图

* **原型设计**: 在动手开发前，绘制仪表板的布局草图。

* **规划交互逻辑**: 明确定义“点击`转化率`视图中的某个指标，下方的`已转化`和`未转化`明细列表需要相应更新”。

## 第二阶段：数据准备与建模

此看板的分析核心是客户的**代际转化**，因此数据准备的重点是准确识别和标记每个客户的身份。涉及到的主要原始数据字段包括：

* **`客户ID`**: 客户的唯一标识符。

* **`订单ID`**: 订单的唯一标识符。

* **`订单营业额`**: 每笔订单的金额。

* **`goods_name` (商品名称)**: 用于判断订单属于哪一代“红旗酒”产品。

* **`filialename` (分公司名称)**: 用于按区域渠道进行下钻分析。

* **`acc_number` / `username`**: 员工的ID和姓名，用于关联销售业绩。

基于这些原始字段，我们通过创建一系列计算字段来构建分析模型，为后续的可视化和交互奠定基础。

## 第三阶段：可视化设计与实现

1. 构建独立工作表

* **KPI工作表 (`转化率KPI 1`, `1.2`, `2`)**:

  * **业务作用**: 为管理层提供最直接的“结果摘要”。通过醒目的大数字，用户无需阅读图表细节，就能在第一时间了解总体转化情况，快速把握业务脉搏。

* **主视图 (`转化率`)**:

  * **业务作用**: 这是分析的核心区域，用于**对比和发现问题**。通过按分公司对转化率进行排序，管理者可以迅速定位表现突出和落后的团队，进而展开针对性的管理或赋能。

* **明细视图 (`已转化明细`, `未转化明细`)**:

  * **业务作用**: 这是**运营落地的抓手**。当管理者在主视图中发现问题后（例如，某个分公司转化率低），可以立即下钻到这个明细视图，查看具体的未转化客户名单，并直接将名单导出，分配给销售团队进行跟进。它将“分析”与“行动”无缝连接起来。

- 选择合适的图表类型

* **文本标记 (大数字)** 用于KPI视图: 最直接，最具视觉冲击力，符合快速浏览的需求。

* **条形图** 用于`转化率`视图: 条形图非常适合进行排名和对比，可以清晰地展示不同分公司在各项转化率指标上的表现差异。

* **文本表** 用于明细视图: 文本表最适合展示详细信息，并且便于用户直接复制或导出数据，满足运营团队获取具体名单的需求。

## 第四阶段：tableau计算与交互实现

1. 仪表板布局与交互设计

* **布局**: 采用“上-中-下”和“左-右”的经典驾驶舱布局，引导用户从宏观到微观进行结构化探索。

* **交互**: 核心交互通过**参数动作**和**筛选器动作**实现。

  * **参数动作**: 用户点击`转化率`视图中的不同指标（如“1代客户转化率”），会动态更新`[参数 2] 转化率选择`的值。这个参数作为一个“开关”，控制着`已转化明细`和`未转化明细`两个工作表的数据筛选逻辑，决定了下方列表展示的是哪个客户群体。

  * **筛选器动作**: 用户点击`转化率`视图中的某个分公司，会将该分公司作为筛选条件，传递给下方的明细列表，从而实现按区域的下钻分析。

- 核心计算字段代码与解析

以下是实现看板功能所有核心计算字段的Tableau代码及其业务逻辑解释。

#### 客户代际判断 (基础标签)

这些字段是所有分析的基础，用于为每个客户打上“代际”标签。

* **`红旗酒-活动代数 (主产品)`**

  * **作用**: 根据商品名称，将每一笔订单精准归类到对应的产品代际。

  * **代码**:

  ```plain&#x20;text
  // 字段名: [活动代数 (主产品)]
  IF [红旗酒-活动代数 (主产品)] = '一代 (2022)' THEN '红旗酒2022'
  ELSEIF [红旗酒-活动代数 (主产品)] = '二代 (2023)' THEN '红旗酒2023'
  ELSEIF [红旗酒-活动代数 (主产品)] = '三代 (2024)' THEN '红旗酒2024'
  ELSEIF [红旗酒-活动代数 (主产品)] = '四代 (2025)' THEN '红旗酒2025'
  ELSE '非主产品'
  END
  ```

* **`是否1代客户`** (后续2、3、4代逻辑类似)

  * **作用**: 使用LOD表达式，从客户的整个生命周期视角判断其身份。无论客户下多少单，只要买过一次1代产品，即被标记为`True`。

  * **代码**:

  ```plain&#x20;text
  {FIXED [客户id],[分公司] : MAX(
      IF [红旗酒-活动代数 (主产品)] = '一代 (2022)' THEN 
          True 
      ELSE 
          False 
      END
  )}
  ```

#### 转化/未转化客户数 (核心KPI)

这些字段用于计算仪表板顶部的KPI指标和明细列表的人数。

* **`1代转化客户数`** (后续2、3代及历代逻辑类似)

  * **作用**: 统计同时满足“是1代客户”和“是4代客户”两个条件的客户总数（去重）。

  * **代码**:

  ```plain&#x20;text
  COUNTD(IF [是否1代客户] AND [是否4代客户] THEN [客户ID] END)
  ```

* **`1代未转化客户数`** (后续2、3代及历代逻辑类似)

  * **作用**: 统计满足“是1代客户”但“不是4代客户”条件的客户总数（去重）。

  * **代码**:

  ```plain&#x20;text
  COUNTD(IF [是否1代客户] AND NOT [是否4代客户] THEN [客户ID] END)
  ```

#### 转化率计算 (核心KPI)

这些字段用于计算`转化率`视图中的核心对比指标。

* **`1代客户转化率`** (后续2、3代及历代逻辑类似)

  * **作用**: 计算1代转化客户数占所有1代客户总数的比例。

  * **代码**:

  ```plain&#x20;text
  COUNTD(IF [是否1代客户] AND [是否4代客户] THEN [客户ID] END)
  /
  COUNTD(IF [是否1代客户] THEN [客户ID] END)
  ```

#### 交互控制字段 (参数动作相关)

这些字段是实现动态交互的关键。

* **`客户转化代数判断.参数`**

  * **作用**: 这是一个布尔型（True/False）计算，它会根据参数`[参数 2]`的当前值，来判断当前行的数据是否属于“已转化”的群体。`已转化明细`工作表使用此字段作为筛选器，值为`True`时才显示。

  * **代码**:

  ```plain&#x20;text
  CASE [参数 2]
      WHEN "1代客户转化率" THEN [是否1代客户] AND [是否4代客户]
      WHEN "2代客户转化率" THEN [是否2代客户] AND [是否4代客户]
      WHEN "3代客户转化率" THEN [是否3代客户] AND [是否4代客户]
      WHEN "1 2 3代客户转化率" THEN ([是否1代客户] OR [是否2代客户] OR [是否3代客户]) AND [是否4代客户]
      ELSE FALSE
  END
  ```

* **`客户未转化代数判断.参数`**

  * **作用**: 逻辑同上，但用于判断“未转化”的群体。`未转化明细`工作表使用此字段作为筛选器。

  * **代码**:

  ```plain&#x20;text
  CASE [参数 2]
      WHEN "1代客户转化率" THEN [是否1代客户] AND NOT [是否4代客户]
      WHEN "2代客户转化率" THEN [是否2代客户] AND NOT [是否4代客户]
      WHEN "3代客户转化率" THEN [是否3代客户] AND NOT [是否4代客户]
      WHEN "1 2 3代客户转化率" THEN ([是否1代客户] OR [是否2代客户] OR [是否3代客户]) AND NOT [是否4代客户]
      ELSE FALSE
  END
  ```
